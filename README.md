# Ayush Patel portfolio

Personal portfolio website: tandem-wing CFD research in ANSYS Fluent, the Elephant Pump project at International Paper, flight training, the Aviation Club at KSU and the Tiny Riddles iOS app.

It's a single static page (`index.html` plus images in `img/`) with no build step. To publish it, turn on GitHub Pages under **Settings → Pages**, set the source to the `main` branch and the root folder, and the site will be at `https://ayushloveayush10-coder.github.io/Ayush-Website/`.
